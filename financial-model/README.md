# Financial model specification

Status: planned; no model has been uploaded.

Recommended modules: source inputs, historical statements, operating adjustments, revenue segmentation, ROIC/EVA, WACC/CAPM, forecast, scenarios, FCFF DCF, equity bridge, relative valuation and sensitivities.

Model checks should reconcile segment revenue to consolidated revenue, balance-sheet totals, cash movements and share counts. Match FCFF with WACC or FCFE with cost of equity; never mix discounting bases. Record units and fiscal periods in every schedule. Separate input assumptions from calculated outputs and dated market inputs.
