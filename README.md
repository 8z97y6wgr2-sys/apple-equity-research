# Apple Equity Research

An equity research and financial valuation project on Apple Inc. (NASDAQ: AAPL), developed by Carlos Pérez, a Finance and Financial Systems student.

The objective is to connect business fundamentals, capital efficiency, cash generation and valuation in a transparent, source-grounded investment thesis.

## Methodology

Use Apple's filings and investor disclosures as primary financial evidence. Record fiscal periods, units, currency and source locations; reconcile totals before modeling. Separate reported facts, analyst adjustments and hypotheses. Define NOPAT and average invested capital consistently before computing ROIC, spread and EVA. Distinguish FCFF from FCFE and pair the cash flow with the correct discount rate. Forecast bear, base and bull cases before DCF and relative valuation; document terminal assumptions and the enterprise-to-equity bridge.

Every final model should expose assumptions, formula checks, source references and valuation-date inputs. A price target should be traceable to the model rather than written ahead of it.

## Tech Stack

Planned analytical workflow: Python, spreadsheets, Markdown, Git and GitHub; Power BI may be used for financial visualization. No executable analysis or financial-model file is included yet.

## Usage

Read the analysis documents and model specification as a research roadmap. There is no executable pipeline to run at this stage. Add actual models, dated source data and reproducible instructions before changing their status to completed.

## Limitations

This is an unfinished educational research project. No valuation conclusion, verified forecast, completed DCF, portfolio recommendation or investment return is claimed. Hypotheses about ecosystem monetization, Services growth, AI or geographic recovery must be tested against source evidence. Results will remain sensitive to growth, margins, reinvestment, WACC and terminal assumptions.
